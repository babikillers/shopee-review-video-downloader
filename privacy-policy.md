# Privacy Policy

Effective date: June 2026

Shopee Video Downloader v2 is a Chrome Extension that helps users detect and download video URLs from Shopee product pages.

## Data Collection

This extension does not collect, sell, rent, share, or transmit personal information to the developer or to any external server controlled by the developer.

The extension does not use analytics, tracking pixels, advertising SDKs, remote databases, or backend services.

## Data Processed Locally

The extension runs locally in the user's browser on supported Shopee websites. To provide its core functionality, it may read information already available on the current Shopee page, including:

* video element URLs
* source element URLs
* browser performance resource URLs
* fetch and XMLHttpRequest URLs observed on the page
* visible product title text
* page metadata used for filename generation

This information is processed locally in the browser only for detecting videos and creating readable download filenames.

## Downloads Permission

The extension uses the Chrome `downloads` permission only to start downloads requested by the user through the extension's Download All button.

Downloaded files are saved by Chrome according to the user's browser download settings.

## Local Storage

The extension uses browser localStorage only to remember whether the floating panel was hidden by the user.

The localStorage key used is:

```text
svd2_panel_hidden
```

This setting remains on the user's device and is not transmitted to the developer.

## Host Permissions

The extension requests access only to supported Shopee regions, including Malaysia, Singapore, Thailand, Indonesia, Philippines, Vietnam, Taiwan, and Brazil, so it can run on Shopee product pages and detect downloadable video URLs.

The extension does not request access to all websites.

## Third-Party Services

This extension does not send user data to third-party services.

Shopee pages themselves may load content, media, scripts, and network resources from Shopee or Shopee-related services. Those services are governed by Shopee's own privacy policies and are outside the control of this extension.

## Personal Information

The extension is not designed to collect or process personal information such as names, email addresses, payment information, passwords, addresses, or account credentials.

Users should not use the extension to download or distribute content unless they have the right to do so.

## Data Retention

The extension does not retain detected video URLs after the browser tab is closed, except for the local panel hidden setting described above.

Downloaded files remain on the user's device according to the user's own file management choices.

## Security

All extension processing is performed locally in the browser. No developer-operated server receives extension data.

## Changes to This Policy

This privacy policy may be updated when the extension changes. Updated versions will be published in the extension's project repository or distribution page.
